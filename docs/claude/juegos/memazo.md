# Memazo — notes for Claude

Screen: `colabtex/src/juegos/memazo.js`; templates (art + text boxes): `colabtex/src/juegos/memazo-plantillas.js`; reducer `redMemazo` at the end of `colabtex/src/juegos/motor.js`. Room game of Juegos, 2–10 players, a party game in the style of *Make It Meme*. The shared architecture (move log, `reducir`, rooms, fin cartel, votes, sound) is in `colabtex/src/juegos/CLAUDE.md`.

- **Rounds:** write (each player picks one of three templates and writes its texts), then rate the memes one at a time, anonymously, 1–5 (🍅😐🙂😂🔥). The ratings go to the author. Room options `rondas` (3/5/7) and `tiempo` (60/90/120 s), both through `$otro`.
- **Moves:** `arranca`, `meme {r,p,x}`, `nota {r,m,v}` and `cierra {r,e,m}`. All of them carry `at`, which the rules check against server time (`jugadas/$n/at`; memazo is on that list). The move that completes a stage, or a `cierra` with `at >= plazo`, opens the next stage at its own `at`. `abandona` has no `at`: if it completes a stage it leaves `completa` set, and the next `cierra` closes it whatever the clock says.
- **The screen writes the clock moves itself**, in a relay: the first active seat writes as soon as a move is due, and every other seat waits 1.8 s more. The reducer ignores the extra ones. Keep that relay: if every tab writes at once, a 10-player room gets ten `cierra` per stage.
- **At the writing deadline the editor sends itself** (`programaEnvio`, `AUTO_MS`): at 2.5 s and 0.3 s before `plazo`, only if there is text and it differs from what was last sent. So that the second send lands first, the `cierra` of the writing stage waits `HOLGURA_ESCRIBIR` (1.5 s) past `plazo` instead of 0.4 s. The reducer still accepts `meme` until that `cierra`.
- **The deadline already counts the reveal** (`MZ_REVELA_MS` before each meme after the first) and the round podium (`MZ_RESUMEN_MS` before rounds 2+). The screen picks what to show from the clock (`vista()`, a 250 ms tick), so a change there must change the deadline arithmetic in `redMemazo` too.
- **Templates must match:** `MZ_PLANTILLAS` in motor.js (id → number of editable texts) and `PLANTILLAS` in `memazo-plantillas.js`. `tests/memazo.test.cjs` checks this by regex: keep each template as `  id: {` … `\n  }`, with its boxes written as `{ x: …` literals. A box with `de: i` repeats text i and is not counted. Offers come from seed + round + seat, and with 27 templates nobody shares an offer up to nine players. Art is flat SVG plus system emoji. Do not use photos of real memes.
- **Template sources (`fuente`, a room option):** `reales` (Imgflip, the default), `gif` (GIPHY) or `dibujos` (the house drawings). `memazo-fuentes.js` fetches them from the browser: Imgflip's `get_memes` needs no key and is cached a day in `localStorage`; GIPHY's key lives in `giphy/clave` (readable when signed in, never written from the web, set by hand in the console like `discord`). Lists can differ between tabs, so an external meme move carries the image itself: `p: "if"|"gif"`, `u` (Imgflip file name / GIPHY id), `an`/`al` (width/height), `n` (title) and `c` (1–5 boxes, `[x,y,w,h]` in %). Built by `jugadaExternaMemazo`. **Never put a number in a move's `h` or `sal`:** the rules reserve those children of every move as strings (other games' hash), and a numeric `h` made Firebase reject the whole move, so «¡Listo!» did nothing. `tests/memazo.test.cjs` reads the rules and checks the move against them. `externoMemazo` validates `u` against each service's format, so nobody can put an arbitrary URL on the others' screens. Drawn templates are accepted in every room and are the fallback when the API fails. Offers and search are client-side only; the reducer does not check that an external template was offered.
- **External templates have no box layout**, so the player drags each box (`.jg-mz-movible`, pointer events) and resizes it from its corner handle; `cajasPorDefecto(n)` is the starting layout. The image is an `<img>` with `referrerpolicy="no-referrer"`; GIFs use the light `200w` rendition in thumbnails.
- **Text fitting:** boxes size in `cqw` (`.jg-mz-meme` is a size container), so `ajustaTextos` fits once and the result holds at any size. Re-fit after Anton loads (`document.fonts.load`).
- **The editor is not repainted by signature while typing.** The draft lives in `borrador` per template, and the preview is updated with `ponTexto`. During rating the screen never shows *who* has voted, because the one who doesn't vote is the author.
- `ocupado()` holds the fin cartel while the last meme's reveal is on screen.
