# Idiomas (i18n.js) — notes for Claude

Applies to every page of the site.

Every page loads `i18n.js` right after `<meta charset>` (`../../i18n.js` or
`../../../i18n.js` in the iframe documents). The 🌐 selector offers Español,
English and Italiano. It draws itself in a `[data-i18n-selector]` slot of the
header, or floats in the bottom-left corner on pages without one, and it never
appears inside an iframe. The choice lives in `localStorage` (`sitio.idioma`),
so the frames read it too. Changing it reloads the page.

**It translates the DOM, not the code.** The apps keep writing Spanish (or
English, in CSV·Scope, which declares `data-i18n-src="en"` and is only
translated when someone explicitly chose a language). `i18n.js` edits text
nodes and attributes (`title`, `placeholder`, `aria-label`, `alt`, `value`)
**in place**: replacing nodes would break the apps' references. A
`MutationObserver` translates whatever gets painted later. Two layers:

- **A curated dictionary.** `i18n/*.txt` holds rows `es || en || it`; `{}`
  marks a hole for patterns. `colabtex/scripts/build-i18n.js` (part of
  `npm run build`, or `npm run build:i18n` alone) compiles them into
  `i18n-datos.js`, which is generated and committed like the bundles. Lookup
  goes exact text, then pattern, then case, then the text stripped of
  emoji/arrows/numbers/punctuation.
- **Machine translation for the rest** (the manuals, long help texts):
  `translate.googleapis.com` `client=gtx`, in batches of lines. It is cached
  in `localStorage` (`i18n.mt.<src>.<lang>`), capped at 800 texts per visit,
  and skips texts where digits outweigh letters (scoreboards, clocks). If it
  fails, the Spanish stays.

**User content must never be translated or sent out.** Anything under
`translate="no"` (or `.notranslate`, editors, `contenteditable`, KaTeX/MathJax,
the pdf.js layers) is skipped. That is why names, project titles and the room
chat carry `translate="no"`, and any new place that paints what a person
wrote needs it too. Code must not compare against a UI string it wrote
earlier (`if (b.textContent === "Copiado ✓")`), because it may have been
translated by then; use a flag (`dataset`).

A new page needs the `<script>` tag. `stamp-version.js` stamps `i18n.js?v=`
on the pages listed in `I18N_PAGINAS`, plus every `juegos/*/index.html` and
`juegos/club/*/index.html`, which it finds by itself, and it fails if a page
in the list lost its tag.
