Matemática del juego: wasm igual a x86, bit a bit

El build de PC de WiiCompiled coincide con la Wii (los ghosts lo prueban). Esta página corre el mismo código del runtime (ppc_isa_float.h, ppc_isa_quantized.h) compilado a wasm con nuestro parche y compara cada resultado con las huellas del build x86 (referencia-x86.txt, hecha con g++ y -march=x86-64-v3). Un millón de casos por operación, muchos raros: NaN con carga, SNaN, infinitos, subnormales, ceros con signo.
