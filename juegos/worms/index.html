MANUAL DE CAMPO / REV. 02

El conocimiento es potencia.

Elimina a los equipos rivales. Cada ingeniero comienza con 120 de vida; la última cuadrilla con supervivientes gana. Las explosiones afectan a aliados y rivales. El agua elimina al instante.

01 / MUÉVETE

A y D para caminar. W para saltar. Tienes una reserva de movilidad por turno. También hay controles táctiles.

02 / APUNTA

Haz clic o arrastra sobre el campo. Ajusta ángulo y potencia con las flechas o los deslizadores. Mantén Espacio para cargar y suelta para disparar.

03 / ELIGE

Teclas 1–9 y 0: arsenal. La cadena Tesla necesita un rival cercano; para Tormenta, marca el destino haciendo clic en el mapa.

04 / EXPLORA

Rueda para zoom, arrastre derecho para cámara. Q muestra todo el escenario; C sigue al ingeniero. Pulsa el minimapa para explorar.

05 / ADÁPTATE

El viento afecta los tiros. Los barriles causan explosiones encadenadas. Recoge cajas de vida y munición caminando sobre ellas.

06 / SOBREVIVE

A partir de la ronda 12 sube el agua. Las caídas muy fuertes también dañan. P o Esc pausará la partida en cualquier momento.
